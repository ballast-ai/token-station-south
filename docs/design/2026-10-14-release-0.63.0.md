## 1. What this release carries

- **#209, image world step I3-3: `image-vertex` 1.0.0.** Nano Banana on Vertex AI `:generateContent`: family
  `vertex-ai-image`, `image-adapter-v1`, capabilities `["generate"]` only (the native arm refuses edits for Vertex), `bearer`
  on the slot `provider_api_key` minted by the `vertex_sa` recipe, contracts `{image: 1, media: 2}`. Its `config_schema`
  entry (`region` required, `project` optional) and its `credentials` section are byte-for-byte those of
  `embeddings-vertex`, so one provider row and one credential's recipe fields can serve both packages. The request,
  response, metering and render are the shared `gemini_image` module with `edit: false`; the reference builds the
  publisher-model route first, so a configuration error (missing region or project, a Vertex base of another region) is a
  500 naming the value before any request refusal. The location rules moved to the crate-private `vertex_location.rs`,
  which `embeddings-vertex` now calls with unchanged behaviour and fixtures. `south_runtime` is 0.59.0, the oldest
  runtime it needs (`contracts.media` 2 first shipped there; the image world's value channel is older). The record's
  six implementation interpretations are in its Implementation section; the configuration refusals are pinned by name in
  `vertex_image_suite` rather than in the gate ② pack (interpretation 1). Gate ① needed no change: the image world has
  had the value channel since 0.52.0 (record §2; the parent record's §18.3 / §18.4 are corrected).
- **#210, the task poll interval (V-Q8).** A task package (`task-adapter-v1` / `task-adapter-v2`) may declare
  `min_poll_interval_seconds`, the shortest interval in whole seconds between two observation requests a host sends for
  one of its tasks, `1..=600` inclusive; absent means the host's own default. Gate ① refuses it in any other world and
  outside the bounds. `task-minimax-v2` declares 12 (lv's ruling V-Q8 (a): one package-level interval) and so takes a
  minor version, 0.32.0; no other task package declares one. No contract number changes. The record's §6 was written
  before #209 and its numbers there are superseded by §4 and §5 here.
- **The release commit** (this branch): the release bump (§5), `task-minimax-v2`'s `south_runtime` moved to 0.63.0 (§4),
  and the release notes (README row and package rows, ARCHITECTURE v0.63.0 paragraph and runtime version, the I3-3
  record's status, this record).

The kernel pin is unchanged (mirror `v0.5.0`, `canonical_ir` 4). `compatibility.json` changes only `release.version`; no
contract number changes.

## 2. API changes

### `south-component-conformance` 0.61.0 → 0.62.0

- New module `reference_vertex_image` and the crate-private `vertex_location` (the region and project readers,
  `base_of`, `origin_of`, `publisher_model_path`); `reference_vertex_embeddings` calls the latter. The references'
  `VERSION` constants follow §4.

### `south-provider-api` 0.55.0 → 0.56.0

- `ComponentManifestV1` gains `min_poll_interval_seconds: Option<u32>`; new `MIN_TASK_POLL_INTERVAL_SECONDS` (1) and
  `MAX_TASK_POLL_INTERVAL_SECONDS` (600); `ManifestErrorV1` gains `MinPollIntervalIsATaskWorldDeclaration` and
  `MinPollIntervalOutOfBounds`, so an exhaustive match on it stops compiling.

`south-contracts` is unchanged (0.54.0).

## 3. Hosts

A host that re-pins keeps serving what it served before; every published package keeps its `south_runtime` and its
`contracts` except `task-minimax-v2` (§4). Serving `vertex-ai-image` needs host work (I3-3 record §6): admit
`contracts.media` 2 (already done for `image-gemini`); bind `vertex-ai-image` with `base_url = "row_endpoint"`; let a
native row whose models route only to image packages take recipe fields (token-station-server `dev-v2`
8eef34c5, I3-3 host H1); confirm the recipe endpoint for the `image-vertex` digest (a confirmation for
`embeddings-vertex` does not carry over); write `region` / `project` config values and set the row's endpoint to the
region's Vertex host; re-mint a minted slot from round 2 on (VI-Q1, on `dev-v2` since 9e9419a5) before serving `n > 1`;
run the dual run against the native arm and the cutover preflight (`vertex-ai-image` row on `dev-v2` 60b1dea5). For
V-Q8 a host reads `min_poll_interval_seconds` and never polls one task of the package more often (the host's H5-5
MiniMax video step; a host that ignores the field keeps its own cadence).
