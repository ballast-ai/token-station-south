Status: prepared on branch `release/v0.64.0` (based on `origin/main` `39e74aa`, which merged #212 to #217); not tagged.

## 1. What this release carries

- **#212, speech S-S-1: the `speech` contract module** (`south_contracts::speech`): the pre-dispatch facts
  (`characters {count, upper?}`, metering forms, reservation bounds, `output_media_type`), `SpeechMeteringV1`
  (characters with `source`, seconds with `basis`, tokens), the artifact forms (`body`, `inline`, `segments`, `url`,
  `container`), the transcript deliveries, the two dialect words, `immutable_form_fields` and `PreparedSpeechCallV1`.
  Speech media types may carry parameters (`audio/L16; rate=24000`, lv 2026-10-14); the image and media grammar is
  unchanged.
- **#214, speech S-S-2: the `speech-adapter-v1` world**: WIT `speech-adapter.wit`, the `SPEECH_*` constants and schema
  row, gate ① (`synthesize` or `transcribe` required; `translate` needs `transcribe`; `artifact_fetch` needs `synthesize`;
  the value channel and `query_parameters` admitted, `quota_headers` and `user_agent` still provider-only), runtime
  `InstanceKind::Speech`, and `UndeclaredValuesIgnored` as one shared function for the `declared`-only worlds.
- **#216, speech S-S-3: the suite `south.speech-component.v1` and the `sse` view**: the component trait and outcome,
  codecs, ABI and sandbox adapters, six additive `CheckV1` rows, a synthetic reference (family `synthetic-speech`, a test
  double no host routes to) passing natively and in the sandbox, host-obligation vectors for the WAV container and the
  `sse` view, and `build_media_sse_response_view_v1` (the host-decoded events elided as one array document, lv
  2026-10-14).
- **#215, `task-minimax-v2` 0.33.0**: declares the native MiniMax arm's six immutable body paths for both generations
  (lv 2026-10-14), so a host injects request extras for it without overwriting them.
- **#217, image refuses `response_body_form: sse` before dispatch**: the image world has no `sse` view, so such a call
  used to be dispatched and every 2xx judged `unknown`.
- **#213, I3-3 record**: §7 V7 corrected (non-image ids reach Vertex and are released under P29). Docs only.
- **The release commit** (this branch): the release bump (§5) and the release notes (README row, ARCHITECTURE v0.64.0
  paragraph and runtime version, the speech and immutable-paths records' status, this record).

The kernel pin is unchanged (mirror `v0.5.0`, `canonical_ir` 4). `compatibility.json` changes only `release.version`:
`contracts.speech` waits for S-S-5, when the first speech packages ship.

## 2. API changes

- **`south-contracts` 0.54.0 → 0.55.0**: module `speech`; `media::MediaResponseBodyV1::Sse`,
  `build_media_sse_response_view_v1`, `SseEventFieldsV1`; `parse_prepared_image_call_v1` refuses `sse`.
- **`south-provider-api` 0.56.0 → 0.57.0**: `SPEECH_ADAPTER_WIT`, `SPEECH_WORLD`, `SPEECH_WORLD_SCHEMA` and the other
  `SPEECH_*` constants; `InstanceDeclarationsV1` replaces the boolean `WorldSchemaV1::instance_declarations`;
  `ManifestErrorV1` gains `SpeechOperationRequired`, `TranslateRequiresTranscribe` and
  `ArtifactFetchRequiresSynthesize`.
- **`south-component-conformance` 0.62.0 → 0.63.0**: the speech trait, outcome, adapters, fixture and suite
  (`run_speech_component_suite_v1`), six `CheckV1` variants, the shared `undeclared_values` row.

**Breaking for hosts on re-pin**: exhaustive matches on `ManifestErrorV1`, `MediaResponseBodyV1` and `CheckV1` stop
compiling, and code that reads or builds `WorldSchemaV1::instance_declarations` must use the enum.

## 3. Hosts

A host that re-pins keeps serving what it served before: no package changes behaviour except `task-minimax-v2`, whose
declared immutable paths let a host inject request extras (the host's H5-5c pin flips to "extras equal on both arms").
The speech world needs host adoption (a generic speech executor, the WAV container and `sse` decoding equal to south's
vectors) before any speech package exists to route to.
