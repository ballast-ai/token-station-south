# Release 0.87.0: Qwen-Audio Flash, Gemini 3.8 TTS, served-model exclusions

Status: released, tag `v0.87.0` (#358, commit `659cdfbc`).

Date: 2026-11-24

Records: [Qwen-Audio Flash, Gemini 3.8 TTS, and served-model exclusions](2026-11-24-tts-flash-gemini38-exclusions.md),
[CI as the verification gate](2026-10-16-ci-as-the-verification-gate.md),
[boundary record](2026-09-30-host-zero-vendor-boundary.md) §13.6 (declared runtime) and §13.12 (Q47),
[release 0.86.0](2026-11-24-release-0.86.0.md).

A minor release that re-identifies every package. It carries the features of issue #357 and the two TTS models lv
asked for on 2026-11-24 in one round, because each of them alone would re-identify every package.

## 1. What this release carries

- **`served_models.exclude_suffixes`** (`south-provider-api` 0.66.0). `speech-qwen` uses it to exclude Model
  Studio's `*-realtime` ids from `bailian-qwen-speech`, so a host refuses to route a Realtime model at the route-time
  check.
- **`speech-qwen` 1.4.0**: serves `qwen-audio-3.1-tts-flash` and bills it by input and output tokens. Each model
  declares its own metering form.
- **`speech-vertex` 1.3.0**: serves Gemini 3.8 Flash TTS and Flash-Lite TTS.
  - It sends the new voice field and asks for raw PCM.
  - It bills by characters or tokens, whichever the host prices.
  - `vertex_location` maps the `us` and `eu` multi-regions to their `rep` hosts. This applies to every Vertex
    package.
- **`url` 2.5.9** in every component lockfile (RUSTSEC-2026-0592).

## 2. API changes

- `south-provider-api` 0.66.0: `ServedModelsV1.exclude_suffixes`.
- `south-component-conformance` 0.82.0: the references above.
- South contract numbers and the kernel tuple are unchanged (`canonical_ir` 5, `stream` 3).

## 3. Hosts

- A host re-pins to the 0.87.0 tag and release index; every package has a new identity.
- `speech-qwen` declares `south_runtime` 0.87.0, because older runtimes refuse its `exclude_suffixes` field. A host
  must link 0.87.0 to load it.
- The server host's deployment preflights must accept the `us` / `eu` multi-region Vertex hosts (record §6).

## 4. Package identities

`south-provider-api` and `south-component-conformance` changed, and every component links them (Q47).
- `speech-qwen` takes the minor 1.4.0 and `speech-vertex` the minor 1.3.0.
- Every other package takes the Q47 patch.
- `served_model_exclusions_retire_every_published_086_package_identity` pins the round. 0.86.0 published the same
  identities as 0.85.1.

Declared runtime: `speech-qwen` 0.87.0. Every other package keeps its declaration.

## 5. The release bump

Step 1 of boundary record §13.12:
- `[workspace.package] version`, 0.86.0 → 0.87.0;
- `compatibility.json` `release.version`;
- the requirements on the workspace-versioned crates in `south-provider-conformance`, `south-testkit`,
  `south-transport-reqwest` and `fuzz`;
- the release-number literal in the workflow test;
- `fuzz/Cargo.lock`;
- `ARCHITECTURE.md`, `README.md` and `docs/releases.md`;
- the 0.86.0 record's status.

The features, the round and the bump are one pull request. `speech-qwen`'s declared runtime names this release, and
the conformance suite refuses a package that declares a runtime newer than the workspace.

## 6. Verification

The gate is the release pull request's CI run. On `release/*` branches the `components` job runs
`scripts/check-declared-runtime.sh --build`, and `crate-versions` and `language` run as well. The release workflow
runs on the tag.

## 7. Not verified

- Neither new TTS model has been called against its upstream.
- The flash token field names are documented, but no example shows them.
- Gemini 3.8's usage fields and billing unit are not on the pages read (record §4).
