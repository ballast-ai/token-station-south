## 1. What this release carries

- **`forwarded_client_policy_headers`.** A provider-world manifest field that names, per family, client headers whose
  meaning does not depend on the request body. A host copies them on every request of that family, including requests
  rebuilt from the IR. `forwarded_client_headers` keeps its rules: it stays tied to pass-through.
- **`bailian-openai-compatible` declares `x-dashscope-datainspection`.** It is the only declaration in this release, and
  `openai-compatible` does not carry it.
- **Gate ① and gate ②.** Gate ① validates the field; `forwarded_headers_absent` covers it, so a component cannot set a
  declared header itself.

## 2. API changes

- `south-provider-api` 0.65.0: `ComponentManifestV1` gains `forwarded_client_policy_headers`; the manifest error enum
  gains `InvalidForwardedClientPolicyHeaders`.
- `south-component-conformance` 0.80.0: `forwarded_headers_absent` reads the new field. The check keeps its identifier.

South contract numbers and the kernel tuple are unchanged (`canonical_ir` 5, `stream` 3).

## 3. Hosts

A host re-pins to the 0.83.0 release index and tag, because every package took a new identity. The field is new, so a
struct literal of the manifest needs it and an exhaustive match of the error enum needs the new variant.

A host adds the forwarding itself; a package cannot do it. Until it does, the declaration has no effect on traffic.
The field does not decide who may use the header: every caller that reaches a declaring family can send it (feature
record §6).

## 4. Package identities

`south-provider-api` and `south-component-conformance` are linked by every component, so every package takes a new
identity (boundary record §13.12, §16 Q47). `provider-openai-compatible` takes a minor, 2.13.6 → 2.14.0, because it
declares the field; the others take a patch.

Declared runtime: **`provider-openai-compatible` raises `south_runtime` 0.77.0 → 0.83.0**, because no runtime before
0.83.0 parses the field. The 29 task, image and speech packages keep 0.81.0, and the other 11 provider and embeddings
packages keep 0.77.0. The tests that pin it move with it: `declared_runtime_now`, the package's rows in
`shipped_packages_v1`, `openai_compatible_t9_v1` and `bailian_openai_compatible_v1`.
