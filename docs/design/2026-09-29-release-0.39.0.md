# v0.39.0 发行内容与验收

本版本基于正式 `v0.38.0 = c9a16763921a7adb9b106d4937588c57dd8caf25`（已含 #113 任务合同 7 与 #114），承接
[v0.37.0 候选](2026-09-28-release-0.37.0.md)（Responses 共享北向 codec，tag 打在本特性分支上、未合入 main）并加入
Responses reasoning 回放载体（token-station-server P15 R 轨，A2 方案 C）。发行包含共享 codec 与十三个组件包；
宿主生产采用仍须各自验收，#42 的关闭以两宿主 R3 验收为准，不以本发行为准。

## 版本边界

运行时 workspace 版本、内部依赖、fuzz 依赖与 `compatibility.release.version` 升至 0.39.0。

**兼容元组改变**：`token-station-protocol` 由 0.3.0（kernel rev `ab6bb2f`）升至 0.4.0（kernel `v0.3.0`，peeled
`f585bc83e5f8a31fbbc6535dd17c3ac8deec6a54`；社区 `kernel-v0.4.0`，peeled `6822aab1dea54ef646cb2206595cd4955ff9764a`），
十三个组件 manifest 的 `compatibility` 一并改为 `ir_schema_id = token-station-protocol@0.4.0/v0.3.0`、
`kernel_version = 0.3.0`、`kernel_revision = 6822aab1…`、`south_runtime = 0.39.0`。元组是包内容，故十三个包身份**全部递增**：
`provider-openai-compatible` 2.1.4、`provider-gemini` 1.1.4、`provider-anthropic` 1.0.5、`provider-bedrock-converse` 1.0.2、
`task-kling` 1.0.4、`task-kling-v2` 0.32.1、`task-minimax-v2` / `task-bailian-v2` 0.31.1、`task-byteplus-v2` 0.36.1、
`task-xai-v2` / `task-veo-v2` / `task-wan-image-v2` / `task-gmi-image-v2` 0.35.1。`shipped_packages_v1` 钉住 0.38.0 发行的
全部身份退役。宿主按 `host_expectations` 精确比对元组：**旧元组的包在新宿主拒载，新包在旧宿主拒载**，两宿主升级时须
同批换 kernel pin、元组与全部包。

锁文件只更新实际 workspace path 包版本与 kernel 依赖，不重解其它第三方依赖；库根 Cargo.lock 按既有规则不提交。

## 行为与宿主边界

- `south-north-codec`：Responses 请求→IR、IR 响应→Responses、IR 流事件→SSE 三组纯映射（v0.37.0 候选内容）之上，加入
  有界协议族载体 `tsr.c1.<base64url(JSON)>`（命名空间 `token-station.reasoning-replay`、版本 1、协议族
  `claude-signed-thinking`），块种类只有 `thinking` / `redacted_thinking` / `text_ref` / `tool_call_ref`，封闭结构、
  未知字段与未知族拒绝；限长 128 块、单块 1 MiB、累计 4 MiB，超限报错不截断。相邻 assistant 合并保留多个 reasoning 项
  及原位置。见 [codec 设计](2026-09-28-responses-north-codec.md)与[逐项证据](2026-09-28-responses-north-codec-validation.md)。
- 流式：thinking / signature / redacted 事件带 `index` 与 `block_index`；聚合器按块首次出现顺序记录布局；
  `response.output_item.done` 与 `response.completed` 复用同一载体串。
- 参考组件 `provider-anthropic` / `provider-bedrock-converse`：请求侧还原完整 thinking / redacted 块与顺序，响应与流侧按块
  身份逐块报出（多块不再合流为 index 0）；不兼容的译器显式拒绝。
- 宿主边界不在本仓：载体的目标筛选（按实际方言与模型显式能力 `reasoning_replay.claude.v1`）、发送前复核、错误码、
  凭证与路由不受载体影响，均由宿主实现（server P15 A2 §5）。codec 不读时钟、不生成随机数、不做准入。
