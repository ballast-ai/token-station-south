# Release 0.87.1: the family catalog covers every world

Status: prepared on branch `release/0.87.1`. Not tagged.

Date: 2026-11-25

Records: [the family catalog](2026-11-24-family-catalog.md) §8a and §8b,
[CI as the verification gate](2026-10-16-ci-as-the-verification-gate.md),
[boundary record](2026-09-30-host-zero-vendor-boundary.md) §13.11 (catalog data) and §13.12 (Q47),
[release 0.87.0](2026-11-24-release-0.87.0.md).

A patch release of release data only. No package changes identity, and no crate API changes.

## 1. What this release carries

- **Speech families in the family catalog** (#359). The 13 `speech-adapter-v1` families get zh-CN / en display names
  and descriptions, and the catalog gains a `vendor-api` group.
- **Image and embeddings families in the family catalog** (#360). The 13 `image-adapter-v1` and 4
  `embeddings-adapter-v1` families get entries; the Vertex entries describe their config keys and credential fields.

`family-catalog-v0.87.1.json` therefore names every family of every world the release carries. The speech, image and
embeddings worlds stay optional in `south.family-catalog.v1`: a family added to them later without an entry does not
fail the release.

## 2. API changes

None. South contract numbers and the kernel tuple are unchanged (`canonical_ir` 5, `stream` 3).

## 3. Hosts

A host re-pins to the 0.87.1 tag and release index, and installs `family-catalog-v0.87.1.json` beside the index. The
packages are the ones 0.87.0 published. The server host's speech binding picker shows the new speech names once it
re-pins; its image and embeddings route editors have no binding picker yet.

## 4. Package identities

Every package keeps the identity 0.87.0 published. Declared runtime: unchanged.

## 5. The release bump

Step 1 of boundary record §13.12:
- `[workspace.package] version`, 0.87.0 → 0.87.1;
- `compatibility.json` `release.version`;
- the requirements on the workspace-versioned crates in `south-provider-conformance`, `south-testkit`,
  `south-transport-reqwest` and `fuzz`;
- the release-number literal in the workflow test (`rust_library_version_is_independent_of_component_runtime_identity`);
- `fuzz/Cargo.lock`;
- `ARCHITECTURE.md`, `README.md` and `docs/releases.md`; the 0.87.0 record's status.

## 6. Verification

The gate is the release pull request's CI run. On `release/*` branches the `components` job runs
`scripts/check-declared-runtime.sh --build`, and `crate-versions` and `language` run as well. The release workflow
runs on the tag; its `release_index.py generate` step checks the family catalog against the archived manifests.

## 7. Not verified

- The image and embeddings entries are not shown by any host yet.
