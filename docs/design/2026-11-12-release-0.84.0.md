# Release 0.84.0: Model Studio speech families

Status: prepared on branch `release/0.84.0`. Not tagged. Merging, tagging and the host re-pin are separate steps; this
commit carries only the release bump.

Date: 2026-11-12

Records: [Model Studio speech families](2026-11-10-speech-bailian-synthesizer-and-minimax.md),
[release 0.83.1](2026-11-04-release-0.83.1.md), [CI as the verification gate](2026-10-16-ci-as-the-verification-gate.md),
[boundary record](2026-09-30-host-zero-vendor-boundary.md) §13.6 (declared runtime) and §13.12 (Q47).

A minor release: it adds two speech families. It also carries 0.83.1, which was merged (#332) but never tagged; lv ruled
on 2026-11-12 to ship it here rather than tag it alone, so its package identities are published for the first time
with this release.

## 1. What this release carries

- **Model Studio speech** (#340, issue #337). `speech-qwen` 1.3.0 adds the family `bailian-speech-synthesizer`:
  Qwen-Audio-TTS and CosyVoice through Model Studio's HTTP SpeechSynthesizer API, for the eight character-billed ids the
  record lists. `speech-minimax` 1.2.0 adds the family `bailian-minimax-speech`: MiniMax synthesis hosted by Model
  Studio, through `DashScope` multimodal generation. Each existing family is unchanged. Neither family has a native arm,
  and no traffic has been captured: every upstream fact is unverified until the check after cutover (record §6).
- **0.83.1's change.** The SSE stream parsers report the first error of a stream in byte order, whatever the chunking
  ([release 0.83.1](2026-11-04-release-0.83.1.md) §1).

## 2. API changes

- `south-component-conformance` 0.81.0, as in 0.83.1 (`SseSplitterV1::push` returns `SsePushV1`). The Model Studio
  families add the public constants `BAILIAN_SPEECH_SYNTHESIZER` (in `reference_qwen_speech`) and
  `BAILIAN_MINIMAX_SPEECH` (in `reference_minimax_speech`). 0.81.0 was never published, so the crate keeps that version
  (`scripts/check_crate_versions.py` compares with `v0.83.0`).

South contract numbers and the kernel tuple are unchanged (`canonical_ir` 5, `stream` 3). No contract, world or host
change is needed for the new families (record §1).

## 3. Hosts

A host re-pins to the 0.84.0 release index and tag, because every package has a new identity. Serving a new family is
then operations: one binding per family on each Model Studio row, routes for the rows, and a smoke test per region.
The host adds both families to its speech family table and its preflight family table. The re-pin is done by the
session that owns the host's re-pins.

## 4. Package identities

Every package carries the identity 0.83.1's Q47 round gave it (`first_error_retires_every_published_083_package_identity`),
published now for the first time, except the two that moved on to minors: `speech-qwen` 1.3.0 and `speech-minimax`
1.2.0 (`the_model_studio_speech_families_join_their_packages`).

Declared runtime: unchanged. A family name is a string a 0.83.0 runtime reads, and neither family declares anything
new. The 29 task, image and speech packages keep 0.81.0, `provider-openai-compatible` keeps 0.83.0, and the other 11
provider and embeddings packages keep 0.77.0.

## 6. Verification

The gate is the release pull request's CI run. On `release/*` branches the `components` job runs
`scripts/check-declared-runtime.sh --build`, and `crate-versions` and `language` run as well. The release workflow
runs on the tag.

The tag itself is not created here.

## 7. Not verified

- No package of this release has been called against an upstream. The Model Studio families' open items are the
  record's §6.
- The fuzz targets have not run on 0.83.1's change in fork mode without findings yet: the first fork-mode run's
  findings were harness defects (#336, fixed by #339); the next scheduled run is the check.
