## 1. What this release carries

- **#188, KC1.** The kernel re-pin to protocol 0.6.0: kernel mirror `v0.5.0` (`356445c15b205f610f060b2f26ca9daa690cbd88`),
  upstream `kernel-v0.6.0` (`c0bca10c2d9f9a439680865feb65c9edf598fc65`), **`canonical_ir` 4**. Every manifest declares
  `ir_schema_id` `token-station-protocol@0.6.0/v0.5.0`, `kernel_version` 0.5.0 and that `kernel_revision`; `compatibility.json`
  records `kernel_contracts.canonical_ir` 4.
  - The IR carries prompt-cache markers on `ContentPart::Text` / `ImageUrl` and `ToolDef`, `Sampling.top_k`, the caller's
    reasoning mode / effort / budget (`reasoning_mode`, `reasoning_effort`, `reasoning_budget_tokens`), and
    `parallel_tool_calls` and `ToolDef.strict` (the R-Q15 promotions). The `responses_tool_strict` map stays in
    `extensions` as a transition fallback.
  - North codec: the Messages decode keeps system / block / tool / tool-result markers, `top_k`, `thinking` and
    `output_config.effort` unconverted, tool `strict` and `disable_parallel_tool_use`, and sends the other top-level keys
    to `extensions` except `metadata`; the Chat decode takes OpenRouter-style part markers and types `reasoning_effort`,
    `parallel_tool_calls` and `strict`. Both refuse an invalid marker, an unknown `thinking.type` and a reserved IR key
    with 400 (`unknown_value` / `out_of_range`, with the field path). Unmarked requests decode to the same IR, byte for byte.
  - **The host value `end_user_hash`** (`south-provider-api`): an opaque per-tenant pseudonym of the caller's end user,
    1 to 128 bytes of `[A-Za-z0-9_-]` (`is_end_user_hash`), which `provider-anthropic` and
    `provider-anthropic-bedrock-invoke` declare and send as `metadata.user_id`.
  - Dialects: the Anthropic and Bedrock Invoke builders emit the markers, `top_k`, a verbatim `thinking` and `strict`, and
    map `parallel_tool_calls: false` to `disable_parallel_tool_use`. The Converse packages emit `cachePoint` for a model
    that declares **`bedrock.converse.cache_point`**, keep a one-hour TTL only with **`bedrock.converse.cache_point.ttl_1h`**
    (otherwise it is sent as the five-minute default), place a tool checkpoint only with
    **`bedrock.converse.cache_point.tools`** (`CACHE_POINT_PARAMETERS`), split cache writes by `cacheDetails`, and send a
    verbatim `thinking` and `top_k` only for a model that declares an `anthropic.*` word. OpenAI-compatible, Gemini and
    Responses drop markers and never refuse them; Gemini sends `topK`.
- **The release commit** (this branch): the workspace bump and every package's `south_runtime` (§5), and the release notes
  (README row and package rows, ARCHITECTURE v0.57.0 paragraph and crate versions, the KC1 record's status, this record).

No south contract number changes (`compatibility.json` `schema_version` stays 7); the kernel contract `canonical_ir` moves
3 → 4.

## 2. API changes

### `token-station-protocol` 0.5.0 → 0.6.0 (the kernel)

See the KC1 record §2 and kernel PR #42. Struct literals of `ContentPart::Text`, `ContentPart::ImageUrl`, `ToolDef`,
`Sampling` and `ChatRequest` gain fields; a pattern `ContentPart::Text { text }` needs `..`.

### `south-provider-api` 0.52.0 → 0.53.0

- New: `HOST_VALUE_END_USER_HASH`, `END_USER_HASH_MAX_BYTES`, `is_end_user_hash`; `HOST_VALUES` gains the word.

### `south-north-codec` 0.56.0 → 0.57.0 (workspace version)

- Behavior only (§1): the new fields, and the new refusals of `chat_request_from_anthropic_messages` and
  `chat_request_from_openai_chat`. No `CodecError` variant is added.

### `south-component-conformance` 0.54.0 → 0.55.0

- New: `reference_bedrock_converse::{CACHE_POINT, CACHE_POINT_TTL_1H, CACHE_POINT_TOOLS, CACHE_POINT_PARAMETERS}`.
- `anthropic_dialect::SAMPLING_NONE` now also drops `top_k`.
- The references' `VERSION` constants follow §4.

`south-contracts` (0.52.0) is unchanged.

## 3. Hosts

**Breaking for hosts on re-pin.** The kernel pin and `HostRangeV1.kernel_contracts.canonical_ir` must move together with
the packages: **a host that records `canonical_ir` 3 refuses every package of this release, and a host at 4 refuses every
earlier package** (the range handshake compares kernel contracts exactly). Protocol 0.6.0's source breaks (§2) apply to
host code. The codecs now refuse requests they used to pass (invalid markers, unknown `thinking.type`, reserved IR keys,
non-string `reasoning_effort` / non-boolean `parallel_tool_calls` on Chat).

To use the new fields a host must also: fill `end_user_hash` for the two Anthropic-family packages (it derives the hash;
the raw `metadata` never enters the IR); remove any `host_values` key from `ChatRequest.extensions` before handing a
request over; learn the three `bedrock.converse.cache_point*` words in its reserved-namespace check and declare them per
model; and price a one-hour cache write from the IR's 5m / 1h split. Hosts that only re-pin serve what they served
before, minus what the new refusals reject.

## 5. The release bump

Boundary record §13.12 step 1: `[workspace.package] version` 0.56.0 → 0.57.0, `compatibility.json` `release.version`, the
requirements on the workspace-versioned crates in `south-provider-conformance`, `south-testkit`,
`south-transport-reqwest` and `fuzz`, and `fuzz/Cargo.lock`. The three guest-linked crates keep the versions #188 gave them
(`south-contracts` 0.52.0, `south-provider-api` 0.53.0, `south-component-conformance` 0.55.0); no component lockfile
changes.

**Every package's `south_runtime` moves to 0.57.0** (§13.6): every package declares `canonical_ir` 4, which no earlier
runtime records, and the two Anthropic-family packages declare `end_user_hash`, which no earlier gate ① knows; 0.57.0 is
the oldest runtime that admits them. As at the 0.46.0 re-pin, the package versions moved in #188 and none bumps again. The
retirement tests stop pinning the runtime each package had when they were written; the "first runtime" tests and
`south-task-core`'s version test assert 0.57.0.
