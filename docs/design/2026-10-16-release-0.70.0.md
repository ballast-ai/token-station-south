## 1. What this release carries

- **#256, `provider-openai-compatible` 2.10.0: the `kimi-code` family.** Native `kimi_code` rows (Bearer, no user-agent
  impersonation) migrated to the generic `openai-compatible` family would stop raising the host's subscription-quota
  alert on a 429; `kimi-code` declares itself in `subscription_quota_families`. The URL is native's
  `{endpoint}/v1/chat/completions` on whatever endpoint the row has (record H2: a row already moved to
  `openai-compatible` with a `{endpoint}/v1` base drops that `/v1` when it moves). The client's `thinking` /
  `enable_thinking` are forwarded as on the other families whose native rows send the client body. The cycle's Q47
  round: `south-component-conformance` 0.69.0, every other package one patch.
- **#257 and #258, the new package `image-openai-compatible` 1.0.0.** The host's OpenAI-compatible image fallback arm
  (D9, kept in the host on 2026-10-13, reconsidered on 2026-10-16) as a package, migrated by the native code, in four
  families:
  - `openai-compatible`, which takes the API root from the row endpoint (a path is the root, a bare origin gets `v1`);
  - `azure-openai-v1` and `azure-openai-dated`, mirroring `speech-openai-compatible` 1.1 (`api-key`, the sanctioned
    `api-version` query, the `api_version` config key);
  - `glm-coding`, the Coding Plan path with the manifest user-agent `opencode/1.15.6`.

  Native money defects are fixed in the package (record D1, D2, D9–D11): images are billed by the count delivered, a
  top-level `input_tokens` is billed, and integral floats are read.
- **#258, the image world admits `user_agent`.** `InstanceDeclarationsV1` gains `UserAgent`, which the image world now
  uses; every other world keeps what it admitted. `south-provider-api` 0.60.0.
- **#254**, docs: the GLM Messages record and the 0.69.0 notes corrected from the host's read-back.

function**: the enum is not `#[non_exhaustive]`. The host session confirmed that token-station-server uses neither
(one comment names the enum).

Host prerequisites:

- H7 (in the host at `51013ebc`): a `glm-coding` image call carries the manifest user-agent through the controlled
  user-agent slot, on the sync and held paths.
