# Release 0.85.0: provider quota metadata normalization

Status: released, tag `v0.85.0` (#345, commit `1a5c5b3e`).

Date: 2026-11-16

Records: [provider quota metadata normalization](2026-11-16-provider-quota-normalization.md),
[release 0.84.0](2026-11-12-release-0.84.0.md), [CI as the verification gate](2026-10-16-ci-as-the-verification-gate.md),
[boundary record](2026-09-30-host-zero-vendor-boundary.md) §13.6 (declared runtime) and §13.12 (Q47).

A minor release: it adds one public host-side interface. No package changes identity.

## 1. What this release carries

- **Provider quota metadata normalization** (#344, issue #342). `south-core` reads a package's
  `ProviderQuotaMetadataV1` and returns the window's limit, what remains, and the absolute reset instant
  (`normalize_provider_quota_v1(metadata, now)`), so a host no longer needs to know which vendor-named slot holds
  which format (a Go-style duration or an RFC 3339 instant) or which slot family wins. The rules are the server host's
  current behavior, with the two edge cases the record's §4 lists removed.

## 2. API changes

- `south-core` 0.85.0 adds `NormalizedQuotaV1` and `normalize_provider_quota_v1`, and depends on `chrono` without its
  `clock` feature (South still cannot read the time; the caller passes `now`).

`south-core` is host-only: no component links it, so no component lockfile, `component.wasm` or package identity
changes (record §3). Quota metadata contract 2 is unchanged; South contract numbers and the kernel tuple are unchanged
(`canonical_ir` 5, `stream` 3).

## 3. Hosts

A host re-pins to the 0.85.0 tag and release index. The packages are the ones 0.84.0 published; the index changes only
in its release number. Adopting the interface is the host's change: the server host deletes `parse_go_duration_secs`
and `quota_snapshot_from` and derives its cooldown from `reset_at` and `now` (record §6; server rectification plan,
candidate 47 / D21). The re-pin is done by the session that owns the host's re-pins.

## 4. Package identities

Every package keeps the identity 0.84.0 published. Declared runtime: unchanged (the 29 task, image and speech packages
0.81.0, `provider-openai-compatible` 0.83.0, the other 11 provider and embeddings packages 0.77.0).

## 6. Verification

The gate is the release pull request's CI run. On `release/*` branches the `components` job runs
`scripts/check-declared-runtime.sh --build`, and `crate-versions` and `language` run as well. The release workflow
runs on the tag.

The tag itself is not created here.

## 7. Not verified

- The interface has not been adopted by a host yet; the server host's adoption is its candidate 47.
- The scheduled fuzz target `contract_parsers` covers the normalization (record §5); it has not had a scheduled run on
  this change yet.
