# v0.37.0 发行内容与验收

本版本基于正式 `v0.36.0 = 76bf632fad0f5500768110bcb3326d16712da66a`（已含 #110、#111、#112），增加 Responses 共享北向 codec。发行包含共享 codec；宿主生产采用仍须各自验收。

## 版本边界

运行时 workspace 版本、内部依赖、fuzz 依赖与 `compatibility.release.version` 升至 0.37.0。十三个组件 manifest 仅更新 `compatibility.south_runtime`；各组件自身 Cargo/package/metadata 版本保持精确基线，尤其 `task-kling-v2` 保持 #111 的 0.32.0。`south-task-core`、`south-task-conformance` 独立库版本不跟运行时递增。kernel revision、IR、WIT、HTTP/auth/error/stream/task 合同版本不变。

锁文件只更新实际 workspace path 包版本，不重解第三方依赖；库根 Cargo.lock 按既有规则不提交。十三包需重新构建，以更新后的运行时元组验收，不能据组件自身版本未变而复用旧 manifest。正式制品身份与发布操作由主线程另行处理。

## 行为与宿主边界

三方向直接 IR 映射、typed/JSON 同源；上下文与每流状态显式传入。五项请求兼容选项分别表达既有宿主差异。错误终态、工具恢复、顺序与序号、用量、JSON 形状均有行为断言。详细设计与 37 行 A1 对照见 [codec 设计](2026-09-28-responses-north-codec.md)及[验收证据](2026-09-28-responses-north-codec-validation.md)。缓存/continuation、准入、计费、Native 透传、context 生命周期与 R 轨保真策略仍在宿主；不扩大 server 工具准入，不宣称解决 #42。
