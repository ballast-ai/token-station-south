# Release 0.88.0: Messages codec thinking blocks and replay markers

Status: prepared on branch `release/0.88.0`. Not tagged.

Date: 2026-11-25

Records: [Messages codec thinking blocks and replay markers](2026-11-25-messages-codec-thinking-blocks-and-replay-markers.md),
[CI as the verification gate](2026-10-16-ci-as-the-verification-gate.md),
[boundary record](2026-09-30-host-zero-vendor-boundary.md) §13.12 (Q47),
[release 0.87.1](2026-11-25-release-0.87.1.md).

A minor release of the host-facing `south-north-codec` crate. No package changes identity.

## 1. What this release carries

- **One wire block per source thinking block** (#362, A1). `AnthropicSseState` maps each IR thinking block
  (`block_index`) to its own content block, as it already does for tool slots. An interleaved stream (thinking, a
  tool call, thinking again) used to render the second block's deltas and signature into the first wire block; each
  block now has its own wire block, signature and stop. `Done` closes every thinking block in IR block order, then
  text, then tools. A stream with one thinking block renders exactly as before.
- **Opt-in Claude replay markers on Messages decoding** (#362, A2).
  `chat_request_from_anthropic_messages_with(body, AnthropicRequestOptions { claude_replay_markers })` marks an
  assistant turn that can carry Claude replay with `reasoning_replay_protocol_family` and
  `reasoning_replay_block_layout`. `chat_request_from_anthropic_messages(body)` uses the default options, and its
  output does not change.

## 2. API changes

- `south-north-codec`: `AnthropicSseState::thinking_index` is removed (breaking, hence the minor version). A host that
  builds the state with `AnthropicSseState::new()` is unaffected. `AnthropicRequestOptions` and
  `chat_request_from_anthropic_messages_with` are added.
- South contract numbers and the kernel tuple are unchanged (`canonical_ir` 5, `stream` 3).

## 3. Hosts

A host re-pins to the 0.88.0 tag and release index. The packages are the ones 0.87.0 published.

Client-visible: a Messages stream with more than one thinking block now carries one block per source block, each with
its own stop. A host whose north-stream snapshots hold such a stream sees them change and judges them when it
re-pins. The default Messages decode is unchanged, so upstream request bodies do not change.

## 4. Package identities

Every package keeps the identity 0.87.0 published; `south-north-codec` is not a component dependency. Declared
runtime: unchanged.
